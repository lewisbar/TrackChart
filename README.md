TrackChart lets you track any numerical data you like and displays it in charts.  
You can track your weight loss journey, how many pages you read in a day, push-ups, scientific data ...

Start by adding your first topic. Choose a name, pick a color palette, start tracking.

You can track positive and negative numbers, decimals or integers, it all works.  
Each entry is automatically timestamped. But you can also change this timestamp to record something you did last Wednesday. 

Supports automatic iCloud sync across devices. Localized for English and German.
